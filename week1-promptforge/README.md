# Week 1 PromptForge

An AI chatbot application built using Groq and Gradio.

## Features
- Multiple AI personas
  - Technical Explainer
  - Debate Coach
  - Code Reviewer
  - Creative Writer
- Few-shot prompting
- Custom system prompts
- Real-time streaming responses
- Gradio web interface

## Tech Stack
- Python
- Groq API
- Gradio
- python-dotenv

## Run Locally

```bash
pip install -r requirements.txt
python test_gradio.py
